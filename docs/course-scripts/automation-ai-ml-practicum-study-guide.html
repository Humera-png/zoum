Part 1 — Week by week

Module 1 — Python Automation Pipelines

WEEK 1

The automation mindset

Covers: spotting which repetitive tasks are worth automating, and Python scripting basics.

Core idea: not everything should be automated — a task that changes every time or happens once a year usually isn't worth it. Automate what's repetitive and stable.

Practice: list 3 repetitive tasks from your own work and note how often each happens and how long it takes by hand.

WEEK 2

File & data automation

Covers: reading/writing spreadsheets with pandas/openpyxl.

import pandas as pd
df = pd.read_excel("weekly_report.xlsx")
summary = df.groupby("region")["sales"].sum()
summary.to_excel("summary_output.xlsx")

Practice: automate one report you currently build by hand — even a simple one.

WEEK 3

Error handling & logging

Covers: try/except, logging.

import logging
logging.basicConfig(filename="run.log", level=logging.INFO)
try:
    result = risky_step()
    logging.info(f"Success: {result}")
except Exception as e:
    logging.error(f"Failed: {e}")

Core idea: a script that fails silently is worse than one that never existed — it gives false confidence. Always log what happened.

Practice: add logging and error handling to your Week 2 automation.

Module 2 — Connecting APIs, Schedulers & Data Sources

WEEK 4

Working with APIs

import requests
response = requests.get("https://api.example.com/data", headers={"Authorization": "Bearer TOKEN"})
data = response.json()

Practice: pull data from one free public API and save it to a file.

WEEK 5

Scheduling

Covers: cron (Linux/Mac) and APScheduler (cross-platform, in Python):

from apscheduler.schedulers.blocking import BlockingScheduler
scheduler = BlockingScheduler()
scheduler.add_job(my_automation, 'cron', hour=6)
scheduler.start()

Practice: schedule your Week 4 script to run automatically once a day.

WEEK 6

Connecting multiple data sources

Core idea: most real automations aren't one API — they're a database, an API, and a file, all feeding one pipeline.

Practice: combine two data sources from earlier weeks (e.g. your Week 2 file and Week 4 API) into a single combined output.

response = ai_client.messages.create(

Part 2 — Troubleshooting

SymptomLikely causeFix
Script works manually but fails when scheduledrelative file paths, or environment differencesuse absolute paths; log the working directory at start
API call returns 401/403bad or expired tokenre-check the auth header; regenerate the key
Script "hangs" with no outputno logging, or an infinite retry loopadd logging at every step; cap retries
Excel file won't open after script runsfile was still open in another program during writeclose the file before running; save to a new file name

Part 3 — Capstone project guide

  1. Pick a real repetitive task from your own work (ideally the one you logged in Week 1).
  2. Map the pipeline: what triggers it, what data sources it touches, what it produces.
  3. Build it using Weeks 1–6: script, error handling, scheduling.
  4. Add one AI/ML-driven decision point from Week 7.
  5. Run it unattended for at least a few real cycles before presenting.
  6. Present it in Week 8: what it replaces, what breaks it, what you'd add next.
