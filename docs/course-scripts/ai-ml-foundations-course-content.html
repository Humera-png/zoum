Module 1 — Python for AI & Data Work (Weeks 1–3)

WEEK 1

Python fundamentals, for data work specifically

Variables, control flow, functions, and working in a notebook environment (Jupyter/Colab) — taught by writing small scripts that touch real data immediately, not abstract exercises.

WEEK 2

NumPy & Pandas

Arrays, DataFrames, loading a CSV, filtering, grouping, and cleaning messy real-world data — the actual daily toolkit of anyone doing AI or data work in Python.

WEEK 3

Exploring & visualizing data

Matplotlib/Seaborn for exploratory data analysis: understanding a dataset before modeling it, spotting outliers, missing values, and obvious patterns visually.

Module 2 — Core Machine Learning Concepts (Weeks 4–6)

WEEK 4

What machine learning actually is

Supervised vs. unsupervised learning, training vs. test data, and the single most important idea in ML: a model that memorizes its training data (overfitting) is not the same as one that's actually learned something useful.

WEEK 5

Core algorithms, conceptually and in code

Linear and logistic regression, decision trees — how each works conceptually, then trained on real data using scikit-learn, so the concept and the code build together.

WEEK 6

Evaluating a model honestly

Accuracy, precision, recall, and the confusion matrix — and why accuracy alone can lie to you (e.g. on imbalanced data). Students learn to distrust a model until they've checked it properly.

Module 3 — Real Datasets, AI APIs & Final Project (Weeks 7–8)

WEEK 7

A real, messy dataset end to end

Take a genuinely messy public dataset through the full pipeline: clean it, explore it, model it. Also: calling an AI API (OpenAI/Anthropic) from Python and using its output inside a project, not just as a chat window.

WEEK 8

Final project

Each student designs, builds, and presents one project that applies what the course covered to a dataset or problem of their own choosing, with instructor guidance throughout.

FAQ

Do I need a math or CS background?

No. Every concept is taught in plain language first, then shown in code. What matters is a willingness to build things and get comfortable being wrong for a while.

What do I need before the course starts?

A laptop and a free Google account for Google Colab (so no local Python install is required to start) — the instructor will confirm setup details before Week 1.

Is this a recorded course?

No, it's instructor-led with live sessions across the 8 weeks.
