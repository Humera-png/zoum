1:10 – 1:40

What machine learning actually is

Supervised vs. unsupervised learning. Training data vs. test data. The single most important idea in the whole weekend: a model that scores perfectly on data it already saw has usually just memorized it (overfitting) — the only score that matters is on data it's never seen.

Live check: "If a model gets 99% on training data and 60% on test data, what happened?" — walk the room to the answer together rather than stating it.

0:10 – 1:00

Evaluating a model honestly

Accuracy, precision, recall, and the confusion matrix:

from sklearn.metrics import confusion_matrix, classification_report
print(confusion_matrix(y_test, model.predict(X_test)))
print(classification_report(y_test, model.predict(X_test)))

Why accuracy alone can lie: on imbalanced data (e.g. 95% of cases are "normal"), a model that always guesses "normal" scores 95% while being useless. Everyone checks their own Saturday model's precision/recall, not just its accuracy.

1:10 – 1:40

Calling an AI API from Python

import anthropic
client = anthropic.Anthropic(api_key="...")
response = client.messages.create(
    model="claude-...",
    messages=[{"role": "user", "content": f"Summarize this finding: {result}"}]
)
print(response.content)

The point: the AI's output becomes part of your own program's output, not a separate chat window — this is the actual skill behind most "AI features" companies ship.
