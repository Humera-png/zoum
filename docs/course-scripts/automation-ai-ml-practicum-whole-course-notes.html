0:00 – 0:15

Open — the automation mindset

Not everything should be automated. Ask the room for 2–3 repetitive tasks from their own work; write one on the board. The test: is it repetitive and stable (doesn't change shape every time)? If yes, it's worth automating — that's the task each attendee will build toward by Sunday.

0:15 – 1:00

Live demo: automating a real report

Instructor builds, live, a script that replaces a report someone currently makes by hand:

import pandas as pd
df = pd.read_excel("weekly_report.xlsx")
summary = df.groupby("region")["sales"].sum()
summary.to_excel("summary_output.xlsx")
print("Report generated:", summary)

The point isn't the specific code — it's showing the whole arc: a manual weekly task, turned into a script that runs in seconds.

1:10 – 2:10

Hands-on: build your own file/data automation

Everyone builds a version of the Saturday-morning demo using their own (or a provided sample) spreadsheet — reading a file, transforming it, writing an output — with the instructor circulating.

2:10 – 2:50

Error handling & logging

import logging
logging.basicConfig(filename="run.log", level=logging.INFO)
try:
    result = risky_step()
    logging.info(f"Success: {result}")
except Exception as e:
    logging.error(f"Failed: {e}")
Core idea: a script that fails silently is worse than one that never existed — it gives false confidence. Everyone adds logging and error handling to their Saturday automation before the day ends.

1:10 – 1:40

Scheduling

from apscheduler.schedulers.blocking import BlockingScheduler
scheduler = BlockingScheduler()
scheduler.add_job(my_automation, 'cron', hour=6)
scheduler.start()

The difference between a script you have to remember to run and one that just runs.
