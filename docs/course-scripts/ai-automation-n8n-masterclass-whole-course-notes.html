0:00 – 0:15

Open

The instructor's own credibility: automation here wasn't learned from a course, it was built to solve real problems — LeadFlowTool, order processing, lead generation, supply-chain automation, all running in production, all built in n8n. Ask the room: "Who has a repetitive task at work they do the exact same way every time?" Take 2–3 answers, write one on the board to return to at the end. Set the goal: "By the time we're done, you will have personally built one real automation."

0:15 – 0:40

What n8n actually is

n8n is a visual workflow tool: connect nodes instead of writing a program. The mental model: Trigger → Action → Action → Action. Why n8n over Zapier/Make: self-hostable, no per-task pricing wall, first-class AI nodes. Live demo: open n8n, show the canvas, add a Manual Trigger, add a Set node, run it once.

0:40 – 1:10

Core building blocks — hands-on

Everyone builds alongside the instructor: Triggers (Manual, Webhook, Schedule — everyone adds a Webhook Trigger and sends a test request); Nodes & data flow (an HTTP Request node reading the trigger's output); Expressions — the one syntax concept in the class:

{{ $json.fieldName }}

Credentials — how n8n stores API keys separate from any node. Checkpoint: everyone has a webhook trigger with at least one node reading its data before moving on.

1:20 – 2:20

The real build — AI-powered lead follow-up automation

The centerpiece, built by everyone from an empty canvas:

  1. Trigger: Webhook, simulating a new lead — { "name": "Priya", "email": "priya@example.com", "message": "Do you take on inventory automation?" }
  2. AI node (OpenAI/Claude): prompt — Write a warm, specific 3-sentence follow-up reply to this inquiry: {{ $json.message }}
  3. Action: send the reply via Email or Slack/Discord
  4. Test: 2–3 different fake leads, showing the AI drafts a genuinely different reply each time
  5. Name the pattern: "trigger → AI decision → action" — the same shape as order processing, lead gen, supply-chain automation, just different nodes

15–20 minutes for people to build it themselves, instructor circulating.
