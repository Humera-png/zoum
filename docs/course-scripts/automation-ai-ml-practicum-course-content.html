Module 1 — Python Automation Pipelines (Weeks 1–3)

WEEK 1

The automation mindset

Identifying which repetitive tasks are actually worth automating (not everything is), and scripting basics: variables, functions, running a script from start to finish.

WEEK 2

File & data automation

Reading and writing files and spreadsheets with pandas/openpyxl — automating a report that someone currently builds by hand every week.

WEEK 3

Error handling & logging

What happens when a script runs unattended and something goes wrong: try/except, logging what happened, and failing loudly instead of silently — the difference between a script and a system you can trust.

Module 2 — Connecting APIs, Schedulers & Data Sources (Weeks 4–6)

WEEK 4

Working with APIs

The requests library, authentication, and pagination — pulling and pushing data to and from other services programmatically.

WEEK 5

Scheduling

Running jobs on their own with cron and APScheduler, so a script executes at 6am every day without anyone starting it manually.

WEEK 6

Connecting multiple data sources

Wiring a database, an API, and a file source into one pipeline — the shape almost every real business automation takes.

Module 3 — Applying AI/ML + Capstone Project (Weeks 7–8)

WEEK 7

Using AI/ML to automate decisions

Not just predictions — using an AI API inside a pipeline to make an actual decision (e.g. classify a support ticket, route a lead, flag an anomaly) so the automation acts, not just reports.

WEEK 8

Capstone project

Design and ship one production-ready automation from an idea the student actually wants running — with instructor guidance and a final review.

FAQ

Do I need to already know Python?

Basic familiarity helps but isn't required — Week 1 covers what's needed to get started, though the pace assumes you can pick up syntax quickly.

What's the difference between this and the Machine Learning Foundations course?

ML Foundations teaches how models work and how to build/evaluate one. This course is about wiring automation systems — APIs, schedulers, pipelines — and using AI/ML inside them to make decisions, not the modeling itself in depth.

What do I need before the course starts?

A laptop with Python installed (the instructor shares setup instructions before Week 1).
